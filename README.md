# Team Generator — CAAI

Aplicación Java desarrollada por el equipo CAAI para la práctica colaborativa de Git y GitHub de 2.º DAM.

## Equipo

- Asier — Scrum Master
- Aarón — Desarrollador
- César — Marketing
- Iker — Contable

## Objetivo

Desarrollar una aplicación de consola en Java que permita consultar información del equipo CAAI, sus integrantes y las tecnologías utilizadas.

## Funcionalidades

1. **Ver miembros:** muestra los integrantes del equipo.
2. **Ver tecnologías:** muestra las tecnologías de cada integrante.
3. **Ver información del proyecto:** muestra información sobre el equipo y el proyecto.
4. **Salir:** permite cerrar la aplicación.

## Tecnologías y herramientas

- Java
- Maven
- Git
- GitHub
